# Alif Najmi — 10-Year Civic Manifesto (2026–2036)

An interactive, scroll-driven 3D web manifesto charting Muhammad Alif Najmi's 10-year roadmap from Business Analyst at `axrail.ai` to Malaysian public office — advocating for enforced bus lanes, continuous shaded sidewalks (*kaki lima*), elderly-first street crossings, and protected cycling infrastructure.

## Stack

- Plain HTML5, Vanilla CSS, Vanilla JS (zero build step, zero bundler)
- Three.js (`r128`) for the scroll-driven 3D Klang Valley street transformation & Kuala Lumpur skyline backdrop

## Run Locally

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Deploy to Vercel

Import `7YMERA/alif-manifesto` in Vercel (**New Project** -> pick `alif-manifesto` -> Framework Preset: **Other** -> Deploy). No build command is required.
